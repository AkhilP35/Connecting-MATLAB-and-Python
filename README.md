# Connecting-MATLAB-and-Python
My edited version of WFSim which allows you to set different turbine angles (phi) for all the wind turbines and calculates the power output at each timestep and averages it. Also converted WFSim_demo into a function which allows it to be able to be run from Python where you can set the yaw angles and recieve the Total Average Power Output.

Didn't realise but WFSim_withpower is a bit invalid as power is calculated in sol.turbine.power which i didnt realise until now :(

Have updated WFSim_simulation_use which has some extra features now aswell
